# Preservation and Deletion Policy

Preserve all existing manuals, images, indexes, and configuration unless the user explicitly approves deletion of exact objects.

A config entry, automation mode, cleanup preference, or unreferenced-file finding is not deletion authorization. Treat same-name files and unexpected existing entries as conflicts. Produce a deletion proposal with reason, impact, and exact paths, then wait for confirmation.

For incremental tasks, modify only declared files and the smallest relevant sections. Preserve encoding and line endings. Do not use broad formatting rewrites.
